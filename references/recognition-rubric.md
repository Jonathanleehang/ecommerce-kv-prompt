# 产品识别评分表（第 1-2 步必读）

识别报告的每一条，后面 10 张海报都会引用。这里写怎么提取、容易错在哪。

两类信息必须区分：**实读**（图上直接看见的文字/颜色/形态）与**推断**（基于品类经验、价格带、包装语言推出来的）。推断项写在方括号里并标「推断」，不要伪装成实读。

---

## 维度 1：品牌名称

提取什么：
- 包装/产品上的 LOGO 文字，中文名与英文名分别记录
- 品牌标志的形式：字标（logotype）、图形标（icon）、图文组合
- LOGO 的字体倾向（衬线/无衬线/手写/定制体）与配色
- LOGO 在包装上的位置（左上角/居中/顶部通栏）

常见坑：
- 英文名别写成推测的规范拼写，以图上印刷为准
- 小字里可能写着"制造商：XX公司"，那是代工厂不是品牌，别混

---

## 维度 2：产品类型

提取什么：
- 大类：服装 / 食品 / 电子 / 美妆 / 家居 / 宠物用品 / 母婴 / 运动户外 / 其他
- 具体产品名：从包装文字或产品形态判断
- 规格：尺寸、容量、重量、数量

判据优先级：包装印刷文字 > 产品形态 > 场景线索。

---

## 维度 3：核心卖点

从三个来源交叉提取，凑够 3-5 条：

1. **包装文案**：标题字、口号、卖点标签（"0添加""7天续航"）
2. **图标与认证**：有机认证、无添加标识、进口标、专利号、获奖标
3. **视觉特征推断**：颜色暗示（白色=纯净/无添加）、材质暗示（玻璃=高级）、工艺暗示（手绘=匠心）

数据类卖点优先级最高——百分比、含量、时长、倍数这类可以被第 9 张参数表海报直接复用。

每条卖点写成「中文 / English」对照形式，后面双语排版直接拿去用。

---

## 维度 4：配色方案

提取什么：
- 包装主色调，给颜色名 + HEX。主色通常 1-2 个
- 辅助色与点缀色（LOGO 金、封口条、标签底色这类小面积色）
- 配色风格：清新 / 沉稳 / 鲜艳 / 高级 / 温暖 / 冷淡

HEX 取值建议取包装大面积色块的代表值，不要取渐变中间色、不要取反光高光处的颜色。

这套色值会成为后面所有海报的画面主色，取偏了整套 KV 都会偏色。

---

## 维度 5：设计风格

- 包装设计风格：极简 / 复古 / 可爱 / 科技 / 艺术 / 国潮 / 田园
- 字体风格：衬线 / 无衬线 / 手写 / 书法
- 图案元素：水彩 / 几何 / 插画 / 摄影 / 纯色块

延伸用途：这一步的判断直接决定第 2 步的视觉风格推荐——KV 视觉应当**延续**包装调性，而不是另起一套。这条逻辑要向用户说清楚。

---

## 维度 6：目标受众

从三条线索推断，都要标注「推断」：
- 包装语言（强调"独自享受""一人食"的多为独居青年，强调"宝宝专用"的是新手父母）
- 品类与价格带（由包装材质、信息层级、是否有烫金工艺推断）
- 视觉复杂度（信息密集多为功效导向的中年用户，极简多为年轻高审美人群）

输出成一句话画像：年龄段 + 身份 + 消费层级 + 核心关切。

---

## 维度 7：产品参数

照抄包装文字，不要整理、不要单位换算：
- 规格（净含量 / 尺码 / 功率 / 容量）
- 成分表 / 配料表 / 营养成分表
- 使用说明 / 注意事项
- 生产信息 / 保质期 / 储存方式

第 9 张参数表海报会把这些原样排进去，任何改写都可能导致错误呈现在成品图上。

图片上看不清的小字，如实标「未识别（需高清图）」，让用户补。

---

## 维度 8：产品细节

- 材质质感：光滑 / 粗糙 / 哑光 / 高光 / 磨砂 / 金属 / 磨砂绒面
- 结构特点：可拆卸 / 折叠 / 便携 / 分装
- 包装特色：自封袋 / 泵头 / 喷雾 / 滴管 / 磁吸 / 撕拉口

这一维度主要服务于第 4-6 张细节特写海报的特写镜头语言描述。

---

## 输出格式

严格按下面这份格式输出给用户过目。缺的字段写「未识别」，不要留空、不要编。

```
【识别报告】
品牌名称：[中文] / [英文]
产品类型：[大类] - [具体产品]
产品规格：[具体规格]
核心卖点：[卖点1 - 中文 / English]
          [卖点2 - 中文 / English]
          [卖点3 - 中文 / English]
          [卖点4 - 中文 / English]
          [卖点5 - 中文 / English]
主色调：[颜色名称] (#HEX) + [颜色名称] (#HEX)
辅助色：[颜色名称] (#HEX)
点缀色：[颜色名称] (#HEX)
设计风格：[风格描述]
字体风格：[衬线/无衬线/手写/书法]
目标受众：[年龄段+身份+消费层级+核心关切]（推断）
品牌调性：[调性描述]
包装亮点：[特殊设计元素/工艺]
产品参数：[规格/成分/注意事项，逐条列出]
```

报告之后紧接着给出**视觉风格推荐 + 排版推荐 + 一句推荐理由**，然后停下来等用户确认。
