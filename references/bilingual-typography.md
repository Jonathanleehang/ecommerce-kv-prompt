# 中英双语排版规范（第 4 步必读）

电商 KV 里的每一个字都要中英文成对出现。原因不只是"看起来国际化"——双语信息层级天然能拉开画面层级，中文做主层级、英文做次级装饰，比单纯堆中文更容易排版。

## 标题排版：三种格式选一

### 格式 A — 中英堆叠（最常用）

```
      纯肉冻干
   PURE FREEZE-DRIED
```

中文在上、字号较大；英文在下、字号约为中文的 45-60%；垂直堆叠、居中对齐。
适用：绝大多数海报的主标题，尤其是竖版 9:16。

### 格式 B — 中英并列

```
纯肉冻干 | PURE FREEZE-DRIED
```

横向并列，用竖线 `|` 或斜杠 `/` 分隔；字号相同或中文略大约 10%。
适用：横版画幅、通栏标题、需要压扁竖向空间的位置。

### 格式 C — 中英分离

```
纯肉冻干                    [左上角]
                    PURE FREEZE-DRIED  [右下角]
```

中英文放在画面对角或不同区块，形成视觉张力。
适用：杂志风、极简风这类大量留白的海报。不适用于信息密集的参数表。

整套 KV 建议锁定一种标题格式贯穿到底。混合使用会削弱系统感——真要混合，至少主 KV（海报 01）与收尾（海报 10）保持一致。

## 卖点/说明文字

```
🥩 100%纯肉 / 100% Pure Meat
❄️ 冻干锁鲜 / Freeze-Dried Fresh
🌾 无谷配方 / Grain-Free Formula
```

规则：图标或符号引导 → 中文在前 → 斜杠 `/` 分隔 → 英文在后。行多时可用上下堆叠（中文在上、英文在下、英文小一号）。

## 段落文字

```
在慵懒的午后，给爱宠一份天然美味。
On a lazy afternoon, give your pet natural deliciousness.

RANOVA冻干零食，用真材实料定义健康零食新标准。
RANOVA freeze-dried snacks redefine healthy treats with real ingredients.
```

规则：中文段落与英文段落分别成段（不混排）；英文段落字号约为中文的 80-90%；行距 1.5-2.0 倍。

## 按钮 / CTA

```
立即选购 SHOP NOW →
了解更多 LEARN MORE →
```

规则：中英文并列或上下排列；箭头符号统一用 `→`（不要用 `->` 或 `>`）。

## 参数表

```
| 营养成分 Nutrients | 含量 Content |
| 粗蛋白 Crude Protein | ≥42% |
| 粗脂肪 Crude Fat | ≥18% |
```

规则：表头必须中英双语；每个参数项都双语标注；数值列只放数字，不翻译。

## 提示词里怎么写排版指令

不要只在 tips 里说"要有中英文"，要在**提示词的画面描述部分**逐处写明：

```
画面上三分之一处为居中双语主标题，采用格式A中英堆叠：
中文"深海赋活"（粗衬线，超大字号，#1A2B4A），
下方英文"DEEP SEA REVIVAL"（无衬线，字距加宽，中字号，#1A2B4A 70%透明度）。
```

这样写，文生图模型才会真的把字排出来。含糊带过、只丢一句 "title with Chinese and English"，出来的多半是一团糊字。

## 字号层级约定

每张海报内部维持 4 级字号，写提示词时用这几个词保持一致性：

| 层级 | 用于 |
|---|---|
| 超大 | 主标题中文（海报 01 可再放大） |
| 大 | 副标题、数字大字报 |
| 中 | 卖点条款、CTA |
| 小 | 英文副行、参数表、注释 |
